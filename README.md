# 🛒 TechNova - Mini E-Commerce Store

A modern, responsive Mini E-Commerce website built using **HTML, CSS, and JavaScript**. TechNova allows users to explore products, search items, filter categories, manage a shopping cart, and preview their orders through an interactive checkout modal.

## 📌 Project Overview

TechNova is a beginner-friendly front-end e-commerce application designed to demonstrate JavaScript DOM manipulation, dynamic product rendering, shopping cart functionality, and LocalStorage.

## ✨ Features

- **Dynamic Product Rendering:** Products are displayed dynamically using JavaScript objects.
- **Product Search:** Search for products by name or category.
- **Category Filtering:** Filter products by Phones, Laptops, and Accessories.
- **Add to Cart:** Add products to the shopping cart.
- **Quantity Management:** Increase or decrease product quantities.
- **Remove Products:** Remove individual products from the cart.
- **Cart Count:** Automatically updates the total number of items.
- **Price Calculation:** Automatically calculates the shopping cart total.
- **Checkout Preview:** Displays selected products and the final price in a modal.
- **LocalStorage:** Saves cart data even after refreshing the page.
- **Responsive Design:** Works on desktop, tablet, and mobile devices.

## ⚙️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Browse products and use the shopping cart features.

No additional installation is required.

## 🛍️ How It Works

1. Products are stored as JavaScript objects.
2. JavaScript dynamically displays the products on the webpage.
3. Users can search and filter products.
4. Clicking Add to Cart adds the selected product.
5. Cart quantities and total prices update automatically.
6. LocalStorage preserves cart information.
7. The checkout modal displays an order preview.
8. Users can confirm the demo order.
